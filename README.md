# BioLingua Daily v9 — Premium Product Edition

v9 在 v8 基础上继续升级成更像真正产品 / 高级行业杂志的版本。

## 新增
- Today's 3 Signals 今日三条行业信号
- 更高级的 editorial / magazine 排版
- 每条新闻增加：风险点、商业/资本视角、求职/入行视角
- 针对不同新闻生成岗位标签
- English Retell 可复述英文句型 + 朗读
- 专业词汇增加英文使用延伸提示
- TED 页面升级为 Daily Issue 风格
- Shadowing + 写作式复盘 + 个人感悟
- 继续保留湖水、倒影、晨光、树木、芦苇等沉浸式自然背景

## 自动更新
GitHub Actions 仍会每天运行 `scripts/update.mjs`，从 5 个来源抓取代表性新闻并生成日期快照。

注意：免费版的自动分析是基于新闻标题/公开 RSS 信息的规则化学习层，不等同于逐篇阅读全文后的专业投研结论。页面会链接原文，重要判断建议回到原文核对。
